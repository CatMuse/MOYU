# MOYU

**墨鱼时间，顺便把英语学了。**

MOYU 是一款 Mac 上的英语学习工具。通过快捷键唤出输入条，利用碎片时间练习单词与句子。

## 下载

首个公开版本正在准备中，目前还没有可下载的安装包。

正式发布后，请从 [Releases](https://github.com/CatMuse/MOYU-Releases/releases) 下载对应版本的安装包。系统要求、支持的芯片类型和安装方式会随版本说明一起提供。

## 使用与试用

- 首次主动唤出练习输入条时，自动开始七天试用。
- 支持单词与句子练习，学习记录保存在本机。
- 正式版本的购买入口位于 MOYU 客户端中，先下载体验，再决定是否购买。
- 永久授权包含当前及未来所有软件版本，可同时激活两台 Mac。
- 首次激活需要联网；激活后可永久离线使用。
