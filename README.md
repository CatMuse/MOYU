## 留在手边，学在日常

MOYU 是一款以输入练习为核心的桌面英语学习应用。通过快捷键唤出输入条，在工作或阅读的间隙练习；结合释义、发音和图片理解内容，再通过输入加深记忆。

当前发布的是跨平台客户端的 **macOS 预览版**。Windows 下载暂未提供。

## 可以怎样学

| 功能 | 学习方式 |
| --- | --- |
| 输入练习 | 练习单词、词组和句子，结合输入反馈巩固记忆。 |
| AI 释义 | 连接自己的 AI 服务，查看释义、例句和拓展；可调整讲解栏目与提示词。 |
| 词光 | 将词汇与图片、释义和发音结合，帮助理解与记忆。 |
| 场景词汇 | 在生活场景中认识物品与表达，把单词放回语境。 |
| 句子课程 | 从词组到完整表达，逐步练习常用句式。 |
| 绘本学习 | 跟随故事与画面练习英语，结合上下文理解句子。 |
| 学习管理 | 浏览课程、管理内容，查看学习记录、掌握情况和练习数据。 |

课程与资源以客户端内容管理中的实际提供情况为准。AI 释义需要自行配置兼容服务，相关服务可能另行收费；图片和录音资源也可能需要额外下载。

## 开始使用

- **唤出或收起输入条**：默认 `⌘ ⇧ M`。
- **展开或收起详情**：默认 `⌘ ⇧ ↓`。
- 快捷键、发音、提示音及练习偏好可在设置中调整；已有设置以客户端显示为准。
- 学习记录保存在本机。在线服务、授权及需要下载的内容仍需联网。
